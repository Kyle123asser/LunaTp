# Changelog

## Alpha V0.2.1

- Adds the GNU AGPLv3 text and AGPL-3.0-only SPDX attribution metadata. Records the public copyright credit as AAAA_Geen.

- Preserves the original V0.2.1 instrument code, plugin and parameter IDs, defaults, and analytical coefficients.
- Retains adjustable Poly Voice Gain, overload indication, and the Traditional Chinese / English editor introduced in V0.2.1.
- Makes the CMake project independent of the original workspace. Pins JUCE 9.0.5 with a SHA-256 check and supports a verified offline archive.
- Adds a portable test entry point and a standalone analytical coefficient generator.
- Prepares a local Windows x64 bundle and publication notes for license review.

## Alpha V0.2

- Added MIDI performance controls, Mono and eight-voice Poly, Legato, Glide, and Pitch Bend.

## Alpha V0.1

- Established the original VST3 synthesis port used for timbre acceptance.
